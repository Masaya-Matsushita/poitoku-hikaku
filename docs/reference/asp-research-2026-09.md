# ASP・収益源調査（2026-09-07）

## 結論

| 収益源 | 個人利用 | 単価目安 | 位置づけ |
|---|---|---|---|
| 各サイトの友達紹介（モッピー・ハピタス） | 可 | 登録時300円前後＋相手獲得分の数〜数十% | **主** |
| 一般ASPのポイントサイト登録案件（A8.net / afb / アクセストレード） | 可（要サイト審査） | 数百円 | 従。モッピーはASP未掲載 |
| ASP経由の広告主直リンク（どこ得の「S」相当） | 可 | 案件による | ユーザーに還元がなくCVRは低い想定。掲載して実測 |
| AppDriver / SKYFLAG（リワード広告網） | 申込書＋審査、実質B2B | 不明 | Phase 4 で流量が出てから再挑戦 |

## 詳細

- AppDriver：申込フォーム/申込書＋必要書類→審査→承諾で契約成立。媒体はアプリ・大手Webメディア想定
- SKYFLAG：規約上メディアは個人可だが「独自審査を通過した限られたメディアのみ提携」。事例はトリマ等のポイントサイト本体
- A8.net：ハピタス、ポイントタウン、ワラウ、ちょびリッチ、ECナビ、アメフリ等の登録案件あり
- アクセストレード：ポイントインカム
- afb：ポイントインカム登録案件168円（2024時点の情報）

## アクション

- Phase 2 公開後：A8.net / afb / アクセストレードにメディア登録し、対象サイトの登録案件を提携申請
- 各ASPの掲載規約（ポイント還元禁止、表現規制）を提携時に確認し `docs/06-legal.md` に追記
- Phase 4：AppDriver / SKYFLAG に問い合わせ
