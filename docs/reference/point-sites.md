#### 利用規約（2026-09-27 確認。https://www.warau.jp/service/guide/rule.html 、平成13年実施・令和7年10月29日 最終改定）

「スクレイピング」「クローリング」「収集」の語は無いが、第19条（著作権等）が、サイトから得た情報を私的利用の範囲を超えて使うことを方法を問わず禁じている：

> 第19条（著作権等）
> 当サイトに関する著作権、商標権などの知的財産権は、当社または当該情報の提供元に帰属し、また、各情報の集合体としての知的財産権は、当社に帰属します。
> 利用者は、当サイトを利用することにより得られる全ての情報において、当社または正当な権利を有する者の事前の承諾なしに、私的利用の範囲を超えて、転載（文章、メールマガジンのリンク）、複製、出版、放送、送信する等、その方法の如何を問わず行ってはなりません。

加えて第15条（禁止事項）は、会員だけでなく「利用者」（第2条：会員・非会員に関わらず当サイトに訪れた個人）に対して次を禁じる：

> 第15条（禁止事項）
> 当サイトの利用者及び会員は、以下の項目に該当する行為を行ってはなりません。
> ・営利を目的とした行為
> ・当社が指定する利用方法とは異なる利用行為
> ・商標権、著作権、意匠権、特許権などの知的財産権及びその他の権利を侵害する行為またはその恐れのある行為

第3条は「利用者となった時点から本規約に承諾したもの」とし、サイトを訪れた時点で適用される。フッターにも「www.warau.jpには著作権が存在し、無断での転載・転用・複製・加工等は禁止いたします」とある。

判定の理由：

- ポイ得比較は案件名・還元額・URL・カテゴリを DB に保存（複製）し、比較サイトとして公開（送信）する。これは「私的利用の範囲を超えて」「その方法の如何を問わず」に当たる。第19条1項は「各情報の集合体」（= 案件一覧そのもの）の権利をワラウに置いている
- ポイ得比較は紹介報酬による収益を第二の目的にしており（`docs/00-vision.md`）、第15条の「営利を目的とした行為」にも当たりうる
- ECナビ 第11条4項（「無断収集・利用…を禁止」）と文言は違うが、掲載情報を集めて公開することを明示的に禁じる点で同じ扱いにする。頻度や節度で回避できる性質のものではない
- 追加するにはオープンスマイルから「事前の承諾」を得る必要がある（許諾の取得はオーナーの判断）

関連する他の条項（参考）：

- 第15条：「サーバー及び当サイトへの不正アクセス等、当サイトの運営に支障を与える行為」「その他、当サイトの運営を妨げる行為」
- 第4条：「日本国外に居住している場合」は入会を承認しない（会員登録の条件。閲覧には地域制限なし）

## 追加時の調査項目

新しいサイトを追加する際は、以下を調査する：

1. **robots.txt**: クローリング許可範囲
2. **利用規約**: スクレイピング禁止条項の有無
3. **データ取得方法**: HTML埋め込みかJS動的ロードか
4. **ポイント単価**: 円換算レート
5. **紹介制度**: 紹介コード/URLの取得
6. **案件一覧の取得方法**: 検索ページ、カテゴリページ等
