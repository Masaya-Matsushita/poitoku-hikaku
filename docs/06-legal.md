# 06 — 法務チェックリスト

Phase 0 で確定し、以後は変更時のみ更新する。

## ステマ規制（景品表示法、2023-10〜）

- [ ] 紹介リンク・紹介コードを含む全ページに「本ページはプロモーションを含みます」を**ファーストビュー**に表示
- [ ] 紹介報酬を受け取る旨を about ページに明記

## クローリング

- [ ] 対象サイトの robots.txt（クローラーが起動時に検証）
- [ ] 対象サイトの利用規約にスクレイピング禁止条項がないか（サイト追加ごとに `docs/reference/point-sites.md` に記録）
- [ ] 公開ページのみ。ログイン必須ページは対象外
- [ ] 取得データの表示は「案件名・還元額・リンク」に留め、サイトのコンテンツを転載しない

## 紹介制度

- [ ] 各サイトの紹介コード掲載ルール（Web掲載可否、表現の制限）をサイト追加ごとに確認

## その他

- [ ] プライバシーポリシー（アラート機能でメール・LINE IDを扱う前に必須）
- [ ] 特定商取引法：販売を行わないため対象外（アラートを有料化する場合は要対応）

## 2026-09-07 規約再確認の結果

### 最大リスクはアカウント停止

オーナーは両サイトの会員で、紹介報酬はそのアカウントに入る。ハピタス規約には「運営の妨害・健全な利用を妨げていると弊社で判断した場合」等の広い裁量条項があり、クローリングの明示禁止はないが運営の判断でアカウント停止＝紹介報酬消滅がありうる。
→ 1日1回・3秒間隔・robots.txt遵守・ログイン不要ページのみ、は法的防御ではなく「運営を不快にさせない」線。厳守する。

- [x] モッピー利用規約本文（2025-12-22改定版）をオーナーが確認（2026-09-22）
  - クローリングを直接禁じる条項なし
  - 第17条①「営利目的の利用」：会員としてのサービス利用を指す読みが自然。公開ページ閲覧・友達紹介（公式にブログ/SNS掲載を許可）は範囲外と判断。ただし⑰・第10条⑫の「当社が不適当と判断」条項があるため節度が全て
  - 第17条⑪「設備の運営に支障を与える行為」：低頻度なら該当せず
  - 第20条：掲載情報の正確性を当社は保証しない → 当サイト側に「還元額は取得時点のもの。必ず公式サイトで確認を」の注記を置く

### 紹介報酬の実際の条件（モッピー、2026-09時点）

- 紹介者300P：友達が入会後180日以内に広告利用で300P以上獲得した場合
- 友達側2,000P：入会月の翌々月末までに広告利用で5,000P以上獲得
- ダウン報酬：友達の対象広告利用が承認されるたび最大10%
→ 「登録数」ではなく「登録して案件をこなした人数」で試算する。ダウン報酬が収益の本体

### 掲載方法（クリア）

- モッピー：ホームページ・ブログ・SNSでの紹介を公式に許可。NGは交換条件提示、サービス紹介以外の文言での誘導、パスワード付き記事、スパム等
- ハピタス：情報商材・セミナー・対価支払いによる誘導がNG。一般的な紹介方法は問題なしと明記
→ 「最高還元サイトの案内＋未登録者向け紹介コード」はサービス紹介の範囲内

### 未確認リスク：案件内容の公開

広告主が「ポイントサイト還元額の公開宣伝」を契約で制限しているケースがあるとの指摘あり。どこ得は掲載しているため実害は小さい想定だが、広告主から削除要請が来たら即時対応する運用とする。
