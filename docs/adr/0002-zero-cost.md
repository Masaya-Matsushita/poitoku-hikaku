# ADR-0002 月額コスト0円の厳守

日付：2026-09-07　ステータス：採択

## 決定

ドメイン代（年約2,000円）以外のコストを発生させない。
手段は「上限設定」ではなく「**支払い手段を持たない**」こと。

## 理由

- GCP には支払いのハードキャップがなく、予算アラートは通知のみ。自律運転するAIに請求アカウントを触らせたくない
- Firebase Spark / Supabase Free / GitHub Free はいずれもカード登録不要で、構造的に0円を超えられない
- 収益が立つ前に固定費があると、集客の壁で止まった半年前と同じ状態になる

## 結果

- 無料枠を超えそうな場合は「機能を削る／規模を絞る」が先。有料化は収益が固定費を上回ってから別ADRで判断
- Supabase Free は7日無アクセスで停止するが、日次クロールで回避される。バックアップは無料枠に含まれないため自前で取る（03-guardrails）
