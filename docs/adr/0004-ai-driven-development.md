# ADR-0004 AI主導開発の運用モデル

日付：2026-09-07　ステータス：採択

## 決定

| 役割 | 担当 |
|---|---|
| 方針・優先順位・KPI定義 | オーナー（このチャットで議論し docs/ に書く） |
| 設計・実装・テスト・デプロイ | Claude Code（対話セッション） |
| 夜間の改善・修復 | Claude Code Routines |
| レビュー・承認・事故対応 | オーナー（週30分〜2時間） |

## 記憶の置き場

Routine は毎回ゼロコンテキストで起動する。したがって**記憶はチャット履歴でも人間の頭でもなく、リポジトリに置く**。

- `AGENTS.md`：規約・禁止事項・参照順序（CLAUDE.md・.cursorrules はポインタ）
- `docs/`：意思決定（ADR）、KPI、戦略。**単一の真実**
- `reports/`：日次・週次の自動生成レポート
- `logs/`：会議記録、事故記録

チャットで決めたことは必ず `docs/` に反映してからClaude Codeに渡す。

## 自律の段階的拡大

1. 初期：自動マージはセレクタYAMLとdocsのみ。コード変更はPRでオーナー承認
2. 1ヶ月事故なし：テスト付きのクローラー変更を自動マージ対象に
3. 以降：事故のたびにガードレールを足し、事故がなければ範囲を広げる

## 「ノーガード」の意味

事前に想定できない事故を想定して防ぐことはしない。ただし `docs/03-guardrails.md` の「初日から入れるもの」は例外で、これは取り返しのつかない事故（対象サイトへの加害、課金、データ消失）の防止である。
