# 別案検討ログ: ふるさと納税など

**日付**: 2026-02-12
**形式**: 壁打ち（方向性の再検討）

---

## このドキュメントの目的

ポイ活比較の収益化モデルに構造的な難しさがあることが判明したため、**別の案を検討した記録**。

最終的に「ポイ活を先に進め、ナレッジを貯めてから横展開する」という方針に決定した。

---

## 1. オーナーの目標

### 最終目標

**個人開発で月数万円程度の副収入を得る仕組みを作る**

### 理想の条件

| 条件 | 詳細 |
|------|------|
| 競合が少ない | 大企業が参入しにくい領域 |
| 高額な報酬 | 1件あたり数百円〜数千円 |
| メンテナンス工数が低い | AIクローリングで自動化 |
| 市場が成長している | 将来性がある |
| **リンクを踏むだけで報酬** | ★新規登録不要であること（重要） |

### 本当のモチベーション

収益化だけが目的ではない。以下も重要な動機：

- **新たな知識・経験を得ること**（プロダクトのオーナーシップ、AI活用、自動化など）
- **楽しさ駆動で開発できること**（本業とは別の「遊び場」）
- **ワンチャンに夢を見られること**（うまくいったらラッキー）

→ **収益化の確度が低くても、これらが満たされるなら続ける価値がある。**

---

## 2. ポイ活比較で学んだこと

### 発覚した問題

**収益化モデルの構造的な難しさ**:
- 比較サイトとして価値を提供しても、新規登録がなければ報酬が発生しない
- 既存ユーザーからは報酬ゼロ
- 直接サイトにアクセスされると報酬ゼロ

**集客の難しさ**:
- SEO: 競合のドメインパワーに負ける
- SNS: 継続的な発信が必要
- 広告: コストが高く赤字になる

### 学びのまとめ

1. 競合調査は最初にやる
2. SEOは甘くない
3. 「メンテナンスフリー」は幻想
4. 集客を先に考える
5. **収益化モデルを先に検証する** ← 今回の最大の学び

## 3. 検討した別案

### 候補一覧

| 候補 | 報酬モデル | 報酬額 | 評価 |
|------|-----------|--------|------|
| **ふるさと納税** | アフィリエイト | 寄付額の1〜3% | リンク経由で報酬、既存ユーザーもOK |
| 格安SIM | 紹介報酬 | 2,000〜5,000円 | 新規登録必須（ポイ活と同じ問題） |
| 証券口座 | 紹介報酬 | 5,000〜20,000円 | 新規登録必須（ポイ活と同じ問題） |
| 電力・ガス | アフィリエイト | 500〜3,000円 | リンク経由で報酬、地域別は競合少ない |

### ふるさと納税の検討

**メリット**:
- 「リンクを踏むだけで報酬」の条件を満たす
- 既存ユーザーからも報酬が発生
- 毎年リピートする

**競合調査結果**:

| サイト | 特徴 |
|--------|------|
| [ふるさと納税ガイド](https://furu-sato.com/) | 23サイト横断検索、還元率ランキング毎日更新 |
| [ふるさと納税クラブ](https://www.furusato-tax.club/) | 還元率&コスパランキング |
| [ふるさと納税大学](https://furusato-univ.com/) | 144万品目を目視調査 |

→ ポイ活の「どこ得」に相当するサイトが**複数存在**する。

**懸念点: 紹介リンクを踏んでもらえない可能性**

| 観点 | ポイ活比較 | ふるさと納税比較 |
|------|-----------|-----------------|
| 来訪時の状態 | 「楽天カード作りたい」など具体的 | 「何かいい返礼品ないかな」と漠然 |
| 購入意図 | 強い（すでに決めている） | 弱い（まだ決めていない） |
| 比較サイトの役割 | 「どこが一番お得か」を調べる → そのままリンクを踏む | 「何があるか」を参考にする → 後で公式サイトに直接アクセス |

**問題の本質**:
ふるさと納税ユーザーは「買いたい商品を決めて来る」わけではない。比較サイトは参考情報として閲覧するだけで、実際に購入するときは公式サイトに直接アクセスする可能性が高い。

→ **比較サイトの紹介リンクを踏んでもらえない = 報酬が発生しない**

## 3.5. 新たな発見：マネタイズモデルの可能性

### どこ得のマネタイズ方法を分析

「どこ得」のリンク構造を調査したところ、**2つの収益源**が存在することが判明。

#### 1. ポイ活サイトの会員登録紹介（友達紹介報酬）

サービス名のリンク先：
```
https://u.gendama.jp/regist/gendama?rid=90000-url&frid=1985777&...
                                                  ^^^^^^^^
                                                  紹介者ID
```
→ ユーザーがこのリンクから新規登録すると、どこ得に紹介報酬が入る

#### 2. ASP経由での案件直接紹介（重要な発見）

案件名のリンク先（「S」マーク付き）：
```
https://appdriver.jp/5/v1/index/171303?identifier=7554404&media_id=5048&...
                                                          ^^^^^^^^^^^^
                                                          どこ得のメディアID
```

**「S」= Sponsored（広告案件）** と推測。

| 表記 | 意味 | リンク先 |
|------|------|---------|
| Sなし | ポイ活サイトの案件ページ | `pc.moppy.jp/campaign/...` |
| **S**あり | ASP経由の直接広告 | `appdriver.jp`、`skyflag`、`gf-rewards` 等 |

### 発見したASP（ポイ活サイト向け）

| ASP名 | 備考 |
|-------|------|
| AppDriver | 複数のポイ活サイト経由の案件で確認 |
| SKYFLAG | 同上 |
| GF Rewards | 同上 |
| ミッションA | トリマ経由の案件で確認 |

### この発見の意味

**当初の懸念**:
> 「ポイ活サイトの新規登録紹介しか報酬がない」→ 既存ユーザーからは報酬ゼロ

**新たな可能性**:
> ASP（AppDriver、SKYFLAG等）と直接提携すれば、**案件紹介でも報酬を得られる**

→ 既存ユーザーが案件に申し込んでも報酬が発生する可能性がある。

### 要調査項目

クロール対象サイトの選定前に、以下を調査する必要がある：

| 調査項目 | 目的 |
|---------|------|
| ASPの提携条件 | AppDriver、SKYFLAG等に個人でも提携できるか |
| ASP経由の案件数 | どの程度の案件がASP経由で紹介可能か |
| 報酬単価 | ポイ活サイト経由とASP直接でどちらが高いか |
| 競合の提携状況 | どこ得以外にASP提携しているサイトがあるか |

### 希望が見えてきた理由

| 観点 | ふるさと納税 | ポイ活 |
|------|-------------|--------|
| 競合の数 | 複数の強力な競合が存在 | どこ得が寡占状態 |
| マネタイズ | リンク踏むだけ（良い） | **ASP提携で案件紹介も可能（良い）** |
| 差別化の余地 | 難しい | UI/UX、速度、機能面で勝てる可能性 |

→ **ポイ活比較を優先する方針は変わらないが、収益化の見通しが改善した。**

## 4. 最終的な方針

### 結論

**ポイ活比較を先に進め、ナレッジを貯めてからふるさと納税に横展開する。**

### 理由

1. **技術的にワクワクする**: どちらも楽しい（モチベーション維持に重要）
2. **構造が似ている**: クローリング → 比較 → 表示、LLM活用、ランニングコスト最適化など
3. **横展開可能**: ポイ活で得たナレッジをふるさと納税に流用できる
4. **収益化の難易度は同程度**: どちらも競合が存在し、集客が課題

### 進め方

```
Phase 0: クロール対象サイト・ASPの調査（★追加）
  - ASP（AppDriver、SKYFLAG等）の提携条件を調査
  - どのポイ活サイトがASP経由の案件を持つか確認
  - 報酬モデル（新規登録 vs 案件紹介）の比較
  - クロール対象サイトの最終選定

Phase 1: ポイ活比較でPoCを実施
  - ランニングコストの最適化
  - クローリング・異常値検知の実装
  - SNS運用の検証

Phase 2: 安定運用できたら横展開
  - ふるさと納税にも同じ仕組みを適用
  - 技術構成・運用ナレッジを流用
```

## 補足: このドキュメントの経緯

1. ポイ活比較の収益化モデルに問題があることが判明
2. 「リンクを踏むだけで報酬」の条件を満たす別案を検討
3. ふるさと納税が候補として浮上
4. 競合調査の結果、ふるさと納税にも競合が存在することが判明
5. ユーザー行動の違い（購入意図の強さ）を分析
6. 「どちらも難しいが、楽しい方を先にやる」という結論に至る
7. ポイ活を先に進め、ナレッジを横展開する方針に決定
8. **どこ得のマネタイズ方法を分析し、ASP経由の案件紹介で報酬を得られる可能性を発見**
9. **クロール対象サイト・ASPの調査をPhase 0として追加**
