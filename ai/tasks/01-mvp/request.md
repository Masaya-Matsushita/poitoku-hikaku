# MVP開発タスク

## 概要

ポイ得比較のMVP（Minimum Viable Product）を開発する。

## 目的

**MVPの目的は「動く仕組みを作る」こと。収益化やプロダクト価値の検証ではない。**

| 観点 | MVPで目指すこと | MVPで目指さないこと |
|------|----------------|-------------------|
| 技術 | Crawl4AIでデータ取得が安定するか検証 | 大規模スケール対応 |
| 運用 | 日次クローリングが自動で回るか検証 | 24/7監視体制 |
| UI | 最低限の検索・表示機能 | 洗練されたUX |
| 収益 | - | 紹介登録、広告収入 |
| 価値 | - | ユーザーに選ばれるサービス |

**2サイト（モッピー・ハピタス）だけでプロダクト価値があるとは考えていない。**

## スコープ

### 含めるもの

| 機能 | 詳細 |
|------|------|
| キーワード検索 | 案件名で検索、部分一致 |
| 比較表示 | 還元額降順のテーブル表示 |
| 対象サイト | モッピー、ハピタス（2サイト） |
| 紹介リンク | 各サイトの紹介URL/コードを表示 |
| 日次更新 | GitHub Actionsで毎日クローリング |

### 含めないもの

| 機能 | 理由 |
|------|------|
| 価格推移グラフ | MVP後に検討 |
| 通知機能 | MVP後に検討 |
| ユーザー認証 | 不要（匿名利用） |
| 案件の正規化 | 複雑なため、検索結果をそのまま表示 |
| 3サイト以上対応 | まず2サイトで安定運用を確認 |

## 開発フェーズ

### Phase 0: PoC（概念実証）← 現在地

**目的**: Crawl4AI でポイントサイトのデータが正確に取得できるか検証

| タスク | 詳細 | 完了条件 |
|--------|------|---------|
| Crawl4AI セットアップ | Python環境構築 | インストール完了 |
| モッピー PoC | 「楽天カード」検索結果を取得 | ポイント数が正確に取れる |
| ハピタス PoC | 個別案件ページからデータ取得 | ポイント数が正確に取れる |
| 精度検証 | 10回実行して再現性確認 | 90%以上の一致 |
| コスト計算 | LLM API費用を試算 | 月額$5以下 |

## 成功基準

### PoC完了条件

| 項目 | 基準 | 具体的な定義 |
|------|------|-------------|
| 数値精度 | 95%以上 | 100件の案件中、95件以上でポイント数が完全一致 |
| 再現性 | 90%以上 | 同一ページを10回取得し、9回以上で全案件が同一結果 |
| コスト | 月額$5以下 | 2サイト×100案件/日で試算 |
| 速度 | 1ページ10秒以内 | LLM抽出込みの処理時間 |

**「正確に取得できる」の定義**:
- 「10,000P」→ `10000` として抽出される
- 「最大10,000円相当」→ `10000` として抽出される（「最大」は無視）
- 「10,000P（条件あり）」→ `10000` として抽出される（条件文は別フィールド）

**PoC失敗時の判断**:
- 精度90%未満 → CSS抽出メインに切り替え
- 精度80%未満 → Crawl4AI採用を再検討

### MVP完了条件

**目的は「動く仕組み」の検証。収益・ユーザー獲得は対象外。**

| 項目 | 基準 | 備考 |
|------|------|------|
| 機能 | 検索 → 比較表示が動作する | 最低限のUI |
| データ | 2サイトのデータが毎日更新される | クローリング自動化 |
| 精度 | ポイント数の取得精度95%以上 | LLM抽出の検証 |
| 可用性 | 本番環境で安定稼働 | Vercel + Supabase |
| 自動運用 | 手動介入なしで1週間以上稼働 | **最重要** |

※ PV数、紹介登録数、収益はMVP完了条件に含めない

## リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| LLM抽出の精度不足 | データが不正確 | CSS抽出にフォールバック |
| サイトのBot対策強化 | クローリング不可 | User-Agent調整、頻度低下 |
| LLM APIコスト超過 | 費用増大 | 使用量監視、上限設定 |
| サイトのHTML大幅変更 | データ取得不可 | LLM抽出で自動適応（期待） |
